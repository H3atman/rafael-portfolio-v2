# Triage labels

Use these exact labels for the corresponding triage roles.

| Label | Meaning |
| --- | --- |
| `needs-triage` | Maintainer evaluation |
| `needs-info` | Waiting on the reporter |
| `ready-for-agent` | Fully specified for autonomous implementation |
| `ready-for-human` | Human implementation required |
| `wontfix` | Will not be actioned |
